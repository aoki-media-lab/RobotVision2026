# C4 軽量な物体検出

キーワード: YOLO，IoU，ONNX

## 問い

- 1枚の画像から「何が・どこに」あるかを一度に出力する検出器は，ネットワークの出力をどう解釈して枠を作っているか
- 検出の良し悪しをどう数値で評価するか．IoU (枠の重なり) と，見逃し・誤検出の数え方 (適合率・再現率) を説明する
- 小さい物体・重なった物体・学習データに無い物体に対して，検出器はどう振る舞うか

## 最初の一歩

- 関数・道具: `cv2.dnn.readNet` または `onnxruntime.InferenceSession`, `cv2.dnn.blobFromImage`, `cv2.dnn.NMSBoxes`
- 最初の実験: ONNX 形式の軽量な検出モデル (YOLO 系や opencv_zoo の NanoDet・YOLOX など) を動かし，
  ネットワークの出力の形 (shape) と各次元の意味を調べてから枠を描く
- 次の実験: 録画した動画の数フレームについて正解の枠を手で付け，IoU を計算して，
  確信度の閾値を変えたときの見逃し・誤検出の数を表にする

## 他テーマとの境界

- **NMS の仕組みの説明・自前実装は C2 が担当**．C4 は `cv2.dnn.NMSBoxes` を使ってよく，**IoU による評価に集中する**
- 検出した物体の追跡は B2, B3 の範囲

## CPUでの注意点

- PyTorch は使わない．ONNX 形式のモデルを OpenCV DNN か onnxruntime で動かす
- 入力サイズ (例: 640 と 320) で速度と小さい物体の検出率がどう変わるかを測る
